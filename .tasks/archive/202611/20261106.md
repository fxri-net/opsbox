# 文档站分类与命名统一

## 计划位置

跨仓文档站规范化 3 / 8；前置：文档站导航规范档案（playbook，任务 1）+ toolkit 样板（仅参照其导航结构，无文件依赖）；目标版本：patch 变更集；依据规范：playbook `fxri-docs-profile` v0.1.0。

## 背景

当前顶栏为 指南 / 操作手册 / 完整攻略 / 参考 / FAQ / 更新日志，一级入口达 6 项；侧栏「更新日志」挂在参考组，「答疑」组只有 FAQ，页面标题仍用「新手指南」「FAQ」。按跨仓规范：分类名 2 字优先、最长 4 字；FAQ 与更新日志统一进「帮助」；页面名统一为「快速开始」「常见问题」；旧 URL 接受 404。

## 顶栏规范

- 一级项 ≤5，首项固定「快速开始」直链，末项固定「帮助」下拉；中间顺序为 指南 → 参考 → 原理 / 升级 / 开发 / 领域组。
- 一级与下拉项文案 2–4 汉字；英文专有名词（CLI、API）按 1 项计，不计入字数上限。
- 单个页面直接作一级直链，不包成单项下拉；下拉项 2–8 个，超出时按二级分组收纳。
- 顶栏与侧栏对同一页面用同一文案；不出现 `FAQ` 等英文缩写；更新日志、常见问题、贡献指南不单独进顶栏。

## 实施方案

1. 顶栏改为 4 项：快速开始（`/getting-started`）、指南（操作手册、完整攻略）、参考（CLI 参考、API 参考、配置参考）、帮助（常见问题、更新日志）。
2. 侧栏改为 4 组：开始（首页、快速开始）、指南（操作手册、完整攻略）、参考（CLI 参考、API 参考、配置参考）、帮助（常见问题、更新日志）。
3. 页面命名对齐：`docs/getting-started.md` H1「新手指南」→「快速开始」；`docs/faq.md` H1「FAQ」→「常见问题」。
4. 新增 `scripts/check-docs-nav.mjs`：校验顶栏项数 ≤5、首项为「快速开始」、末项为「帮助」、帮助内含常见问题与更新日志、分组名汉字数 ≤4（纯页面条目（含一级直链）豁免；一级项与任何层级的分组名不豁免）、链接目标存在、不出现裸 `FAQ`；按规则实现，不维护页面白名单；脚本头注释标注标准来源与版本（playbook `fxri-docs-profile`）；接入 `scripts/verify.mjs`。
5. 新增 `docs/404.md`（统一兜底页：首页 / 常见问题 / 更新日志入口 + 搜索提示），旧 URL 不重定向但可继续导航。
6. 校验脚本增加页面体量告警：单页 >300 行（排除 `changelog.md` 镜像）输出 warn，不阻断。
7. 全量修内链与页面称呼；新增 patch 变更集。
